# Demand Forecasting Dashboard

An interactive and dynamic AI-powered Demand Forecasting Dashboard built for the Gen-AI Hackathon 2026. This application uses machine learning (Prophet) to predict future demand and generates executive narratives using Gen-AI.

## Features
- **Dynamic Forecasting**: Adjust forecast horizons and see real-time updates.
- **Interactive Visualizations**: View historical data, trends, and seasonal components.
- **AI Executive Summary**: Get automated, context-aware narratives and actionable insights.

## Tech Stack
- **Frontend**: Streamlit
- **Machine Learning**: Prophet (Time Series Forecasting)
- **Data Manipulation**: Pandas
- **Visualization**: Matplotlib

## How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/Gen-AI-Hackathon-2026/Team-B8.git
   ```
2. Make sure you have your dependencies installed (Streamlit, Prophet, Pandas, Matplotlib, python-dotenv).
3. Run the application:
   ```bash
   streamlit run app.py
   ```
